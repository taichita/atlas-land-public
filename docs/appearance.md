# 外観

上部の色のボタン、または「メニュー → 外観・テーマ」で変更します。

| プリセット | 配色 | 書体 |
|---|---|---|
| Nebula | 紫・ダーク | 明朝 |
| Midnight | 青・ダーク | ゴシック |
| Code | 緑・ダーク | 等幅 |
| Paper | 生成り・ライト | 明朝 |
| Lavender | 薄紫・ライト | ゴシック |
| Daylight | 白・ライト | Windows標準 |

モード、アクセント、背景の明るさ、書体、文字サイズ、発光、星の動きは個別に調整できます。個別変更すると「カスタム」になります。プリセットを選び直すと、その配色・書体・サイズへ戻ります。

外観は全ウィンドウ・全ペインで共有し、変更を即時表示してサーバーの `workspace.json` の `appearance` へ保存します。WebページやHTML成果物自身の配色・画像には色変換をかけません。

検証: `node test/appearance-e2e.mjs`。6プリセット、カスタム書体・明度、再読み込み後の復元、2ウィンドウと子ペインへのイベント同期を個人データなしで確認します。
