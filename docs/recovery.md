# Atlasが見えなくなったとき

Atlas LandはWindowsアプリです。展開先の `dist/AtlasLand.exe` を再び開いてください。実行中のAI作業があると、ウィンドウを閉じても通知領域に残る場合があります。

会話・設定・下書きは `%LOCALAPPDATA%\PersonalAIWorkspace\data`、Webログインなどは同じ保存先の `webview` に残ります。ウィンドウを閉じただけで保存データが削除されることはありません。

Atlas内で始めたAI作業はローカルCodexを使用します。Codexアプリが起動していると、既存の会話を同期し、Atlasからも同じ会話へ指示できます。Atlasで始めた案件は、実行中の応答や送信予約が終わってからCodex側と共有します。「Codexで開く」でも同じ会話を開けます。共有後のAI実行はCodexアプリが担当するため、両方の画面を使う間はCodexも起動しておいてください。

Codexの再起動・更新で接続先が変わった場合は、自動で探し直します。応答が途切れた指示を勝手に再送することはありません。送信結果が不明な場合は、会話の更新で確認してください。

表示エンジンが異常終了した場合は、AIの実行サービスを維持したまま画面を作り直します。復元に失敗してもアプリを閉じず、「画面を復元」から再試行できます。スリープ復帰時にはCodexとの接続と会話を更新します。

Windows Updateなどの再起動に備えて、Windowsのアプリ再起動機能へ登録します。再表示されるかはWindows側の再起動条件・設定によります。PC再起動で中断したAIの指示は自動再送しません。表示の復元では、保存済みのタブや下書きを戻します。Webページ内の未送信フォームなどは復元できない場合があります。

起動や終了の記録は同じ保存先の `lifecycle.log`、内部サービスのエラーは `host-errors.log` に出力します。調査のためにログを共有する場合は、ファイルパスなどの個人情報が含まれないか確認してください。
