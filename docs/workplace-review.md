# Atlas Browser — 職場での利用確認

個人開発のWindows用AIワークスペース兼ブラウザです。OpenAIの公式製品ではありません。これは利用許可の判断材料であり、会社での利用許可を表すものではありません。

## 配布と必要環境

- ZIPを全展開し、`dist/AtlasBrowser.exe` を起動する形式です。インストーラー・自動更新・自動起動の登録はありません。
- Windows 11 x64、.NET Framework 4.8、WebView2 Evergreen Runtime、Node.js 24が必要です。Codex連携には利用先PCのCodexと認証が必要です。
- 署名なしの試用版です。会社のソフトウェア配布・実行制限に従って導入します。
- 配布物にはアプリコード、本番ライブラリ、フォント、ライセンスを収録します。作成者の会話・認証・ブラウザプロファイル・作業ファイルは収録しません。

## データと接続

- タブ、会話、下書き、保存前バックアップ、WebログインはWindowsユーザーごとの `%LOCALAPPDATA%\PersonalAIWorkspace\` に保存します。
- Codexの認証・Skills・MCPは、そのPCにある設定を利用します。私用PCの設定は自動移行しません。
- AIに送る指示や添付内容、ツール実行の情報はCodex経由で処理されます。閲覧サイトや設定済みMCPにも、その操作に応じた通信が発生します。
- Atlas内部のサービスはループバックアドレスで待ち受けます。既存Codex会話の同期にはCodexアプリの起動が必要です。
- 会社指定のアカウント・契約と、業務情報をAIへ入力できる範囲を確認してください。個人契約の業務利用が認められるかは会社側で判断します。

## 実行権限

現在の配布版は個人用と同じ動作です。新規案件は既定で `danger-full-access` / `never` を使用し、AIは実行ユーザーがアクセスできる案件外ファイルやShell・Gitも、個別確認なしに操作できます。Atlasは管理者権限を要求しませんが、作業フォルダ内に操作を制限する設定ではありません。

この権限が職場の条件に合わない場合は、導入前に確認付き実行・対象フォルダの制限などを組み込んだ職場用設定を用意する必要があります。現版には組織管理者による設定の固定や集中監査の機能はありません。

## 検証範囲

開発PCでの起動と機能テスト、配布ファイルの検査を実施します。職場PCでの初回セットアップ、プロキシ、WebView2、Codexの接続、社内サイトとの互換性は未検証です。まず許可されたサンプルデータで動作を確認する想定です。
