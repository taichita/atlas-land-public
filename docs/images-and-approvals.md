# 画像の貼り付けと承認

チャット入力欄でCtrl＋Vを押すと、クリップボードの画像を添付できます。「＋ 画像」から選ぶ方法と、入力欄へのドラッグ＆ドロップにも対応します。サムネイルを押すと拡大し、×で送信前の添付を外せます。

PNG・JPEG・WebP・GIF、1枚12MBまで、1回8枚まで。画像だけでも送信できます。貼り付けた画像はこのPCのAtlasデータ領域へ保存し、送信を押すまではAIに渡しません。送信前の画像は再起動後にも復元し、送信失敗時は残します。

Atlasが実行する案件には、公式App Serverの`localImage`入力として渡します。Codexアプリ側の既存案件は現在の送信APIがテキストのみのため、保存した画像のパスと、画像ツールで確認する指示を渡します。後者の画像閲覧は、そのタスクの実行環境・ツール・アクセス権に依存します。

承認画面には、要求された質問文・選択肢・入力欄を表示します。「回答して進める」「拒否」「キャンセル」を区別して送信します。回答は同期で消えず、複数の承認がある場合は残りを表示し続けます。自動で承認したり、承認ポリシーを緩めたりする変更はしていません。

通常のMCPフォームの文字列・数値・真偽値・単一選択・複数選択に対応します。URL形式は確認ページを開き、ユーザーがそこで完了した後に結果を返します。独自のフォーム形式は回答用JSON欄に切り替えます。Codexアプリ側の既存案件で確認待ちになった場合は「Codexで確認」から承認元を開きます。同期用の接続口には、承認回答を送る機能がありません。

仕様確認: [公式Codex App Serverの画像入力・承認・MCPフォーム](https://learn.chatgpt.com/docs/app-server)（2026-09-09確認）。

検証: `npm test`、`node test/image-approval-e2e.mjs`、`node test/ui-check.mjs`。画像と承認の結合テストでは、一時データと模擬App Serverを使用し、実際のAIや外部操作を呼びません。

Windows版でも実際のクリップボード画像を右ペインのチャットへCtrl＋Vで貼り付け、サムネイル表示とローカル保存を確認済み。確認用の画像は未送信の下書きとして残しています。
