# 縦型タブ

各ペインの左端にタブを縦に並べます。普段は幅46pxのアイコン表示で、カーソルを合わせると一覧が広がり、タブ名と検索欄が表示されます。カーソルを離すと畳まれます。

- 一覧を縦にスクロールして選択。検索はそのペイン内のタブ名を対象にします。
- ×で閉じる、ドラッグで並べ替え・別ペインへの移動。
- 下部のボタンからメモ・Web・ファイルを追加。
- Tabキーで移動すると一覧が開き、Escapeで畳めます。
- 一覧の表示だけでWebタブを読み込んだり、AIを呼び出したりしません。

WebView2のWebページは一覧の右端から表示します。ドキュメントは一覧の下に重なり、ホバーのたびに本文全体の組版を変えません。
