# 複数ペインと独立したタブ

2026年9月10日更新。ペイン数の固定上限をなくし、各ペインが独立したタブ列を持つようにしました。

- 上部の「＋ ペイン」、または Ctrl + \ で追加します。選択中の画面を新しいペインにも開きます。
- 右側を含め、各ペインの「＋ Web」「＋ ファイル」から、そのペインにタブを追加できます。追加ボタンはタブ列のスクロール領域から分け、常にペインの右端に表示します。
- Ctrl + T、Ctrl + W、Ctrl + Tab、Ctrl + Shift + T は操作しているペイン内で働きます。
- Ctrl + Alt + ← / → で前後のペインへ移動します。
- 「ペインを閉じる」、ペイン内の「▥×」、または Ctrl + Shift + W で選択中のペインを閉じます。最後の1ペインは残ります。タブを閉じても、案件・ファイルは削除しません。
- 「タブを隣へ」、ペイン内の「⇥」、または Ctrl + Alt + M で、選択中のタブを次のペインへ移動します。
- タブをつかんで別のペインへドラッグ＆ドロップすると移動します。タブ列の上なら挿入位置を選べます。同じペイン内で並べ替えることもできます。Esc、またはペインの外で離すと中止します。
- 「格子状」「横並び」「縦並び」で配置を変更できます。縦並びは横の境界で高さ、横並びは縦の境界で幅を変更できます。格子状では行・列ごとにサイズを調整します。境界を選んで矢印キーでも変更できます。サイズは配置ごとに保存し、再起動後も復元します。
- ペインの配置と各ペインのタブ・選択位置は保存され、次回起動時に復元します。従来の右ペイン設定も引き継ぎます。

表示中のWebページはペインごとのIDでWindows側へ渡し、ショートカット・別タブで開くリンク・ネイティブ操作の応答を元のペインへ戻します。Webタブの旧30個上限も撤去しています。ペインと読み込んだページの数に応じてPCのメモリは使用します。

Webタブを別ペインへ移動・入れ替えすると、移動先でURLを開き直します。ログイン情報は共通のブラウザプロファイルに残りますが、ページ内の未送信フォームや一時的な表示状態までは移動しません。
