# ショートカットとローカル機能

メニュー → キーボード ショートカット、またはF1で一覧を開く。操作名やキーで検索でき、割り当て欄を選んでキーを押すと即座に保存される。重複した割り当ては相手の操作と交換する。Deleteで解除、行の↺で個別に初期化、「すべて初期設定に戻す」で全体を初期化できる。V/Zの動画操作は初期状態でON。同じ画面でON/OFFとキーを変更できる。

| キー | 操作 |
| --- | --- |
| V / Z | 表示中のWeb・ローカル動画を＋0.25 / −0.25倍。範囲0.25〜8倍 |
| Ctrl+T / Ctrl+W | 新しいWebタブ / タブを閉じる |
| Ctrl+Shift+T | 閉じたタブを復元（起動中の直近20件） |
| Ctrl+Tab / Ctrl+Shift+Tab | 次 / 前のタブ |
| Ctrl+PageDown / Ctrl+PageUp | 次 / 前のタブ（別の割当） |
| Ctrl+1〜8 / Ctrl+9 | 番号のタブ / 最後のタブ |
| Ctrl+Shift+PageUp / PageDown | タブを左 / 右へ並べ替える |
| Ctrl+L | アドレス入力・検索 |
| Ctrl+\（￥） | ペインを追加。各ペインは独立したタブ列を持つ |
| Ctrl+Shift+W | 選択中のペインを閉じる |
| Ctrl+Alt+M | タブを次のペインへ移動 |
| Ctrl+Alt+← / → | 前 / 次のペインへフォーカス |
| Ctrl+Shift+N | 新しい案件 |
| Ctrl+Shift+B | サイドバーの表示切替 |
| Ctrl+Enter | AIへの送信 |

V/Zは入力欄、編集可能な文章、IME変換中、キーリピート中には発動しない。埋め込みフレームと開いたShadow DOM内のvideoにも対応。ブラウザ外のネイティブアプリの動画や、video要素を使わない独自プレーヤーは対象外。

WebView2のドキュメント作成時にスクリプトを登録し、キー操作時だけ動画を列挙する。ページを監視する常駐タイマーやAI呼び出しは使わない。一般Webページのメッセージは `atlas.mediaStep` の±0.25だけ受け付け、表示中のWebペインの再生速度だけを変更する。ファイル、Shell、AI送信などのワークスペース操作とは接続しない。

## ローカルファイル

ファイル欄の「ローカルを開く」からWindowsのファイル選択を開く。案件フォルダの外にあるTXT、Markdown、CSV、JSONなどもAtlas内のタブで読み書きできる。文字コードはUTF-8、UTF-16 LE、Shift-JISに対応し、保存前にファイルの変更を検知する。ローカルファイルは案件のAIコンテキストへ自動添付せず、必要なときに内容を確認してから会話へ貼り付ける。

## 次に追加したいローカル機能（提案・未実装）

1. **資料保存** — [SingleFile](https://github.com/gildas-lormeau/SingleFile)のページ保存機能を参考に、参考記事を案件のフォルダへ保存し、出典URLと会話にひもづける。動画制作の資料収集に最も合う。
2. **広告・追跡の制御** — [uBO Lite](https://github.com/uBlockOrigin/uBOL-home)を参考に、ローカルのルールで不要な通信を抑制。サイトごとにON/OFFを切り替えられる形を検討する。
3. **サイトごとの読書配色** — [Dark Reader](https://darkreader.org/)を参考に、明るさ・背景色・コントラストをサイト単位で保存。Atlasのテーマとは別に調整する。

拡張機能をそのまま動かせる保証とは別に、必要な機能をAtlasのローカル機能として統合する案。採用するコード・ライブラリの互換性とライセンスは実装時に確認する。
