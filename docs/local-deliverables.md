# 成果物の保存場所

exe・ZIP・大きな成果物を案内するときは、親フォルダへのリンクと、コピーできるWindows形式のフォルダパスを併記します。Markdownのリンク先は `C:/...` のようにスラッシュで書き、空白がある場合は `<...>` で囲みます。

Atlasでフォルダへのリンクを押すと、そのフォルダをWindowsで開きます。exe・ZIPなどの配布物や、編集上限を超える文章ファイルは、ファイルの親フォルダを開きます。実行ファイルを自動実行することはありません。動画・PDF・画像など、対応するプレビューは従来どおりAtlasで開きます。

古いバックエンドが「ファイルを選んでください」やサイズ上限のエラーを返す場合も、更新後の画面はWindowsの保存場所表示に切り替えます。この補修は画面の再読み込みで反映でき、Codexで実行中の作業を終了する必要はありません。2026-09-19に生成した社内セットアップexeは変更していません。
