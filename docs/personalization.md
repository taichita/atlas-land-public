# Atlas Browserの普段の操作

- 「既定フォルダ」でAIの普段の作業場所を一度選びます。メモの保存先は別に記憶します。
- 案件の×で一覧から片づけます。履歴は保管に残り、新しいやり取りが発生すると戻ります。
- `Ctrl+Shift+B`で案件一覧を隠します。新着の返答があると左端にテーマ色の印が出ます。押すと最新の新着案件を開きます。
- 通常起動は空の1ウィンドウ。`Ctrl+N`で追加します。手動で閉じるとタブとペインを片づけます。会話、書きかけの指示、ファイルの下書き、ログインは残します。
- 縦タブの★へマウスを合わせ、フォルダもホバーでたどれます。ページや案件は`Ctrl+D`で登録します。
- メモは`Ctrl+Alt+N`で書き始め、`Ctrl+S`ですぐ保存します。ファイルを開く選択画面は記憶したメモフォルダから始まります。

## 音声入力と接続

「メニュー → AIの接続・音声入力」にCodexの接続、Groq/OpenAIの音声設定をまとめています。既存のGroq Dictation設定があれば、そこにあるGroqのキーを読み取ります。保存場所を選んでコピーする必要はありません。

会話の入力欄でマイクを押すと録音し、もう一度押すと文字起こしします。×で録音を破棄できます。結果は入力中の案件の下書きへ入り、勝手に送信しません。音声の接続先はAIのモデルごとに記憶します。

APIキーはこのWindowsユーザーのアプリ保存先にある`data/connections.json`からも設定できます。「設定ファイルを開く」でAtlasのエディタに開けます。キーのない項目は利用できません。Codexの月額枠は音声APIの料金に充当されません。録音は選択したGroqまたはOpenAIへ送り、Atlasは録音ファイルをディスクへ保存しません。文字起こしの失敗時は再試行するまでメモリに残ります。

Claude Code・Gemini・Kimiの会話実行や月額アカウント接続は未実装です。既存のClaude利用量表示とは別の機能です。

俯瞰は現在の案件と依存関係から描き、状態の通知が来ると更新します。隠れているときは描画を休止します。保管した案件は俯瞰にも表示しません。

確認した公式仕様（2026-09-19）: [Codex App Server](https://learn.chatgpt.com/docs/app-server)、[OpenAI音声認識](https://developers.openai.com/api/docs/guides/speech-to-text)、[Groq音声認識](https://console.groq.com/docs/speech-to-text)。
