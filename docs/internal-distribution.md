# Atlas Browser 社内用セットアップ

Windows 11 x64 向けの社内評価・業務利用版です。一般公開用ではありません。

## 使い始める

1. `Atlas-Browser-Internal-Setup.exe` を実行します。Windowsの発行元表示は未署名です。配布元とSHA-256を確認してください。
2. AIの作業フォルダと権限を選び、インストールします。標準の「通常」はPC全体の操作を確認なしで許可します。フォルダ内の編集・読み取りのみも選択できます。
3. デスクトップの「Atlas Browser (社内版)」を開きます。
4. AIを使う場合は、本人のPCにCodexを導入し、Atlasの「メニュー → 設定と接続 → ChatGPTでログイン」から本人のアカウントを接続します。Codex未導入でもブラウザとローカルファイル閲覧は起動できます。

Node.jsは同梱しています。WebView2が不足する場合は、セットアップがMicrosoft公式インストーラーを実行します。この場合はインターネット接続が必要です。会社の端末管理で導入が禁止されている場合は管理担当者に確認してください。

Codexは `%LOCALAPPDATA%\OpenAI\Codex\bin` 内の実行ファイルを検出します。別の導入方法の場合は `AI_WORKSPACE_CODEX` に `codex.exe` の絶対パスを設定できます。Codexの既存会話同期はバージョン依存のため、評価対象に含めてください。Claude Codeなどの接続をこのセットアップが自動で構成することはありません。

## データと権限

- AIの月額料金・API料金は各利用者の契約で負担します。配布者の契約・APIキーは付属しません。
- 会話・設定・Webログインは `%LOCALAPPDATA%\PersonalAIWorkspace` に保存されます。既存のAtlas環境がある場合は同じユーザーデータを使います。
- 再インストールしても保存済みの既定フォルダ・権限・ブックマーク設定は上書きしません。権限の変更は「設定と接続」から行い、新しい案件に適用します。Codex側の既存会話の権限はその実行元の設定に従います。
- 権限はAIの実行範囲を選ぶものです。人間がブラウザでファイルを開く操作を制限する端末管理機能ではありません。
- Chromeのブックマーク取り込みはセットアップ時に選択できます。既存のGroq Dictation設定ファイルからAPIキーを自動で取り込みません。音声入力は本人が接続設定を行ってください。
- AIに送る指示・添付ファイル・音声は選択したAIサービスに送信されます。業務データの利用可否は会社のルールに従ってください。

## 更新・削除

Atlasで保存し、実行中のAI作業が終わってから社内版を終了し、新しいセットアップを実行します。自動更新・常駐アップデーターはありません。更新時は別のアプリフォルダに展開し、ショートカットの参照先を切り替えます。

Windowsの「インストールされているアプリ」から「Atlas Browser (社内版)」をアンインストールできます。アプリ本体の登録ファイルだけを削除し、会話・ログイン・作業ファイルは残します。
