# すぐに書くメモ

1. タブ右端の「＋ メモ」（`Ctrl+Alt+N`）を押します。初回だけ作業フォルダを選びます。
2. 選んだフォルダ直下に重複しない無題のテキストファイルを用意し、入力欄へフォーカスします。書きかけの文章はAtlasの下書き領域へ自動保存します。
3. 初回の「保存」（`Ctrl+S`）でファイル名と保存先を確認します。「変更」で別フォルダも選べます。「キャンセル」でも文章は残ります。
4. 保存後は通常のファイルとして編集・上書き保存できます。同名ファイルや他のアプリによる変更を検出した場合は上書きしません。

作業フォルダは全ウィンドウで記憶します。「メニュー → メモの作業フォルダ」から変更できます。「＋ ファイル」で既存ファイルを開く場合にも、記憶したフォルダから始まります。

検証: `node --test test/notes.test.mjs` と `node test/notes-e2e.mjs`。個人データ・AIを使わず、初回だけのフォルダ選択、即時入力、自動下書きと復元、保存キャンセル、同名保護、別名保存を確認します。
