# すぐに書くメモ

1. 縦タブ下部の「メモ」（`Ctrl+Alt+N`）を押します。初回だけ作業フォルダを選びます。
2. 選んだフォルダ直下に重複しない無題のテキストファイルを用意し、入力欄へフォーカスします。書きかけの文章はAtlasの下書き領域へ自動保存します。
3. 「保存」（`Ctrl+S`）ですぐ保存します。本文の先頭行と一意な時刻からMarkdownのファイル名を作り、記憶したフォルダへ保存します。名前や保存先を毎回選ぶ必要はありません。
4. 保存後は通常のファイルとして編集・上書き保存できます。同名ファイルや他のアプリによる変更を検出した場合は上書きしません。

作業フォルダは全ウィンドウで記憶します。「メニュー → メモの作業フォルダ」から変更できます。「＋ ファイル」で既存ファイルを開く場合にも、記憶したフォルダから始まります。

閉じたメモは「ファイル」から開き直せます。選択画面はメモの保存フォルダから始まります。

検証: `node --test test/notes.test.mjs` と `node test/notes-e2e.mjs`。初回だけのフォルダ選択、即時入力、自動下書きと復元、ダイアログなしのCtrl+S、同名保護、保存後の再編集を確認します。
