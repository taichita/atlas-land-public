# ブックマーク

- 縦タブの★・♥・◆・⚑へマウスを合わせると、そのマークの一覧が開きます。項目を1クリックで開けます。
- Webのアドレス欄の☆へマウスを合わせ、保存したいマークを押して登録します。登録済みならマークを変更します。Ctrl+Dは★への登録、登録済みページでは編集です。
- 会話タブではCtrl+D、またはマークの一覧の「＋ 登録」で、その案件を登録できます。
- Chromeからの項目は★へまとめます。プロファイル名・フォルダ階層を表示せず、奥の項目まで直下に並べます。同じURLは一覧で1つにまとめます。
- 「整理・Chromeから同期」「メニュー → ブックマーク」、Ctrl+Shift+Oから名前・URL・マークの編集、検索、削除ができます。
- ブックマークはウィンドウ共通です。マークも保存され、再起動後に引き継ぎます。
- ChromeのローカルBookmarksを片方向に読み取ります。Googleアカウントとの同期そのものはChromeが行います。Chromeへの書き戻しはありません。
- 起動時と一覧を開く際に更新を確認します（30秒以内の連続読込はまとめます）。Atlasで編集・削除した項目は保持します。同じURLの重複分もまとめて削除します。
- Chromeが別のカスタム保存先を使う場合は自動検出の対象外です。

検証: `node --test test/bookmarks.test.mjs test/personalization.test.mjs`、`node test/bookmarks-e2e.mjs`。個人データ・AIなしで確認します。
