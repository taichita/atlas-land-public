# ブックマーク

- Webのアドレス欄にある☆、または `Ctrl+D` で現在のページを登録します。
- 「ブックマーク」ボタン、「メニュー → ブックマーク」、`Ctrl+Shift+O` で一覧を開きます。名前とURLで検索できます。
- 一覧の項目を押すと、そのウィンドウ・ペインの新しいWebタブで開きます。
- 一覧の「編集」、または登録済みページの★から、名前・URLの変更と削除ができます。
- ブックマークはウィンドウ共通で、ローカルの `workspace.json` に保存します。外部への同期はありません。同じURLを登録しても重複しません。

検証: `node --test test/bookmarks.test.mjs`、`node test/bookmarks-e2e.mjs`。登録、検索、編集、再読み込み、削除、別ウィンドウへの反映を、個人データ・AIなしで確認します。
