# ブックマーク

- Webのアドレス欄にある☆、または `Ctrl+D` で現在のページを登録します。会話タブではCtrl+Dでその案件を登録できます。
- 縦タブの★へマウスを合わせると一覧が開きます。フォルダもホバーでたどり、項目を1クリックで開けます。
- 整理は「整理・Chromeから同期」「メニュー → ブックマーク」、`Ctrl+Shift+O` から開きます。名前・URL・フォルダー名で検索できます。
- 「＋ フォルダー」で保存先を作成します。フォルダーを開いてさらに子フォルダーも作れます。「編集」の保存先でブックマークやフォルダーを移動できます。項目が残るフォルダーは削除しません。
- 一覧の項目を押すと、そのウィンドウ・ペインの新しいWebタブで開きます。
- 一覧の「編集」、または登録済みページの★から、名前・URLの変更と削除ができます。
- ブックマークはウィンドウ共通で、ローカルの `workspace.json` に保存します。
- 通常のWindows版起動では、このPCのChromeのDefault/ProfileフォルダにあるBookmarksを読み込みます。Googleアカウントとの同期そのものはChromeが行い、Atlasはそのローカルコピーを片方向で取り込みます。Chromeへの書き戻しはありません。
- 起動時とブックマークを開く際に更新を確認します（30秒以内の連続読込はまとめます）。常駐監視プロセスは追加しません。Atlas側で名前や場所を変えた項目、削除した項目は再取り込みで元に戻しません。
- Chromeが別のカスタム保存先を使っている場合は自動検出の対象外です。

検証: `node --test test/bookmarks.test.mjs`、`node test/bookmarks-e2e.mjs`。登録、検索、編集、再読み込み、削除、別ウィンドウへの反映を、個人データ・AIなしで確認します。
