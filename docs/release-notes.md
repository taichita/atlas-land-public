Windows x64向け試用版です。添付ZIPを全展開して `dist/AtlasLand.exe` を開いてください。必要な環境と操作方法はZIP内の「はじめに.md」に記載しています。

Codexの現在の接続方式に合わせて同期を修正しました。接続先の変更を自動検出し、Atlasで始めた会話も応答完了後に同じIDのまま共有します。「Codexで開く」を追加しました。実行中のAIの移動や、送信結果が不明な指示の自動再送は行いません。

表示エンジンの異常終了から画面を復元し、起動失敗時もアプリを閉じず再試行できるようにしました。スリープ復帰時には接続と会話を更新します。Windowsのアプリ再起動機能に登録し、終了理由と復旧の記録を残します。

この版には、ホバーで展開する縦型タブ、タブ検索、複数ウィンドウ・ペイン、メモ、ブックマーク、外観設定、CSV表示の修正を含みます。

タブ欄の★から、ファイルや会話を見ているときもブックマークを開けます。フォルダーを作成し、入れ子で整理・移動できます。チャット切替時は最新の返答を表示します。

Webの「日本語訳」と右クリックからページ内を翻訳できます。「自動翻訳」はサイト単位で有効にします。既存のCodex接続で翻訳し、接続先の利用枠を使います。入力欄・コード欄は翻訳対象から除外します。Atlasを日常の作業場としていることも、新規・継続するAI会話へ伝えます。

チャットの最新履歴の後ろに、古い発言と応答が再び表示される不具合を修正しました。進行中の返答だけを新着表示へ加え、過去の会話は履歴から表示します。会話データの削除や再送は行いません。

アプリを終了して新しいZIPを別フォルダへ展開すると、同じWindowsユーザーの保存済みデータを引き継いで起動できます。実行中のアプリを自動更新する機能はまだありません。
