## ローカル更新：ブックマークとペイン拡大

Chromeのブックマークをフォルダ階層なしで表示し、★・♥・◆・⚑で整理できるようにしました。登録時にマークを選べます。同じURLの重複は一覧でまとめ、削除後に別プロファイルから再表示されないようにしました。

Ctrl+Shift+Enterでペインを一時拡大し、同じキーで元の分割幅に戻せます。裏のタブと下書きを保持します。

Windows x64向け試用版です。添付ZIPを全展開して `dist/AtlasBrowser.exe` を開いてください。必要な環境と操作方法はZIP内の「はじめに.md」に記載しています。

0.4.0: 名前をAtlas Browserへ変更し、地球を抱えるAtlasのアイコンとGeorgiaのブランド書体を採用しました。

新しい案件の既定フォルダを記憶します。案件の×は一覧から片づけ、新しい動きがあれば再表示します。手動で変えた案件名は同期後も保持します。Ctrl+Shift+Bで案件一覧を隠せ、新着時には左端へテーマ色の通知を表示します。

通常起動は1ウィンドウ・空のタブです。Ctrl+Nで追加できます。手動で閉じるとそのウィンドウのタブをリセットし、会話・ログイン・下書きは保持します。表示エンジンの障害からの復旧では作業中の表示を復元します。

縦タブの展開幅を約3分の2へ縮め、AI・サイト・動画・画像・音声をアイコンで区別します。Webのアイコンはそのページから取得します。メモは初回に選んだフォルダへCtrl+Sで直接保存します。

Chromeのローカルブックマークをフォルダごと取り込みます。★にマウスを合わせ、フォルダもホバーでたどり、1クリックで開けます。案件もCtrl+Dで登録できます。同期はChromeからAtlasへの片方向で、Atlas側の編集は保持します。

接続が切れた案件には「再接続」を追加しました。「AIの接続・音声入力」からCodexの接続と音声入力のAPI設定を管理できます。既存のGroq Dictation設定も利用します。録音の文字起こしは下書きに挿入し、送信はユーザーが行います。Groq/OpenAIの音声APIは各APIの利用枠を使います。Claude/Gemini/Kimiの会話実行・月額アカウント接続はこの版の対象外です。

Codexの現在の接続方式に合わせて同期を修正しました。接続先の変更を自動検出し、Atlasで始めた会話も応答完了後に同じIDのまま共有します。「Codexで開く」を追加しました。実行中のAIの移動や、送信結果が不明な指示の自動再送は行いません。

表示エンジンの異常終了から画面を復元し、起動失敗時もアプリを閉じず再試行できるようにしました。スリープ復帰時には接続と会話を更新します。Windowsのアプリ再起動機能に登録し、終了理由と復旧の記録を残します。

この版には、ホバーで展開する縦型タブ、タブ検索、複数ウィンドウ・ペイン、メモ、ブックマーク、外観設定、CSV表示の修正を含みます。

タブ欄の★から、ファイルや会話を見ているときもブックマークを開けます。フォルダーを作成し、入れ子で整理・移動できます。チャット切替時は最新の返答を表示します。

Webの「日本語訳」と右クリックからページ内を翻訳できます。「自動翻訳」はサイト単位で有効にします。既存のCodex接続で翻訳し、接続先の利用枠を使います。入力欄・コード欄は翻訳対象から除外します。Atlasを日常の作業場としていることも、新規・継続するAI会話へ伝えます。

チャットの最新履歴の後ろに、古い発言と応答が再び表示される不具合を修正しました。進行中の返答だけを新着表示へ加え、過去の会話は履歴から表示します。会話データの削除や再送は行いません。

アプリを終了して新しいZIPを別フォルダへ展開すると、同じWindowsユーザーの保存済みデータを引き継いで起動できます。実行中のアプリを自動更新する機能はまだありません。
