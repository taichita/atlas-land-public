# Atlas Browser 0.4.3

## Codexアプリの自動復旧

- Atlas利用中、同期の切断が20秒以上続いたらCodex本体の起動状態を確認。終了している場合は、Windowsに登録された最新版を起動して同期を再試行します。
- 起動失敗が続く場合、Codexが終了していることを再確認してMicrosoft Store版の更新を試します。更新確認は6時間に1回まで。Storeの同意・認証・管理ポリシーが必要な場合は、更新を完了できない旨を表示します。
- 設定に「今すぐ復旧」と、自動復旧・更新の切替を追加。切断した会話にも「復旧」ボタンを表示します。
- 起動試行は15分に3回まで。動いているCodexを強制終了せず、会話・ログイン情報を初期化しません。送信・承認を自動再送せず、切断中も作業完了と判定しません。
- 本体が起動したまま固まった場合の強制再起動や、中断したAI処理そのものの自動再実行は対象外です。

詳しくは docs/host-recovery.md を参照してください。

## 下書き保存とCodex同期の修正

- 大きな会話応答でサーバーが終了する不具合を修正。受信サイズを制限し、該当する会話は軽量表示へ切り替えます。元の会話は変更しません。
- 下書き保存を順番に処理し、遅れて完了した古い保存による上書きを防ぎます。
- 保存失敗は自動再試行。チャット下書きを保存完了までブラウザ内にも退避し、同じ警告の連続表示を抑えます。
- ローカルファイルへの保存後に完了を応答します。AIへの指示や承認は自動再送しません。

## YouTube制作ツール

- おすすめ欄の上にYouTube Studioの視聴者維持率を表示。グラフをクリックして再生位置を移動できます。初回のみ、自分のGoogle Cloud OAuth JSONとチャンネル所有者の読み取り許可が必要です。
- Ctrl+Shift+Y：提供されている字幕と、現在のWebペインのスクショをまとめて保存。字幕を取得できない場合はスクショを保存し、その旨を表示します。
- Ctrl+Alt+Y：現在のサムネイル・タイトル・チャンネル名・尺を使うおすすめカードのプレビュー。
- F1でキーを変更できます。設定方法は docs/youtube.md を参照してください。実アカウントのAnalytics取得は利用者による接続後の確認が必要です。

Windows x64向け試用版です。ZIPを全展開して dist/AtlasBrowser.exe を開いてください。exe単体では起動しません。必要な環境はZIP内の「はじめに.md」に記載しています。

## 接続が切れて動かなくなる問題の修正

- 裏側のサーバーが終了した場合、画面・Webタブ・編集中の入力を保って自動復旧します。停止が続く場合は「再接続」から再試行できます。
- 画面だけが終了した場合も、開き直すと残ったバックエンドへ再接続します。二重起動を防ぎます。
- Codexの利用上限を「AI利用上限」として表示し、Web閲覧・ファイル編集と区別します。失敗した指示を自動再送しません。
- 接続が切れている間の利用量を「未更新」と表示し、古い使用率を現在値として表示し続けないようにしました。
- 復旧時に案件と利用量を更新します。終了理由の記録を追加しました。

## 前の公開版からの改善

- ブックマークを★・♥・◆・⚑で分類し、ホバーで一覧からすぐ開けます。Chromeのローカルブックマークもフォルダ階層なしで取り込めます。
- Ctrl+Shift+Enterでペインを一時拡大し、同じキーで元の分割幅へ戻せます。
- AIの回答全文と、コード・プロンプト枠それぞれにコピー操作を追加しました。
- 公開ページの翻訳はGoogle翻訳を標準にし、Codexによるページ内翻訳も選べます。
- exe・ZIP等の保存場所を開きやすくしました。

通常起動は空の1ウィンドウです。会話・下書き・ログインはWindowsユーザーのローカル保存先に残ります。更新前には作業を保存してください。実行中アプリの自動アップデートは行いません。

AIには利用者自身のCodex環境と認証が必要です。音声入力APIは別途設定が必要です。Claude・Gemini・Kimiとの会話実行は今回の配布版の対象外です。
