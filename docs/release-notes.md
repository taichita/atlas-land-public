Windows x64向け試用版です。添付ZIPを全展開して `dist/AtlasLand.exe` を開いてください。必要な環境と操作方法はZIP内の「はじめに.md」に記載しています。

この版には、ホバーで展開する縦型タブ、タブ検索、複数ウィンドウ・ペイン、メモ、ブックマーク、外観設定、CSV表示の修正を含みます。

チャットの最新履歴の後ろに、古い発言と応答が再び表示される不具合を修正しました。進行中の返答だけを新着表示へ加え、過去の会話は履歴から表示します。会話データの削除や再送は行いません。

アプリを終了して新しいZIPを別フォルダへ展開すると、同じWindowsユーザーの保存済みデータを引き継いで起動できます。実行中のアプリを自動更新する機能はまだありません。
