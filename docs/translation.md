# ページの日本語訳

標準は「Google · 公開ページ」です。「日本語訳」を押すと、公開ページのURLをGoogle翻訳へ渡し、Atlas内の別タブに翻訳表示を開きます。APIキーは不要で、AtlasからCodexや翻訳APIへの有料リクエストは行いません。元のタブは残します。GoogleのWebサービス側で表示できないページやログインが必要なページでは「Codex · ページ内」に切り替えてください。

Googleを選択している間は、保存済みのCodex自動翻訳設定も動きません。ローカル・社内用ホスト名、IPアドレス、認証情報を示すクエリを含むURLはGoogleへ渡しません。公開URLかどうかを完全に判別する機能ではないので、社内データのページではCodex側の接続先も含め会社の方針に従ってください。

以下は「Codex · ページ内」を選んだ場合の動作です。

Webの「日本語訳」または右クリックの「日本語に翻訳」を使います。「自動翻訳」をオンにしたサイトは、次回表示や文章の追加時にも翻訳します。「原文」で元の表示へ戻せます。自動翻訳のサイト設定はウィンドウごとに保存します。

ログイン中のページでも、同じページ内の文章を置き換えます。URL・ログイン状態・入力値は変更しません。Codexの既存接続へ対象の文章を送信するため、その接続先の利用枠（API認証の場合はAPI利用量）を使います。秘密値を含む入力欄、編集欄、コード欄、非表示要素は収集しません。APIキーによくある形式も対象から除外しますが、一般の文章として表示された機密情報まで完全に判別する機能ではありません。

翻訳は一時的な会話で実行し、Atlasの案件一覧や会話履歴には追加しません。Shell・Web検索・構成済みMCP/プラグインを無効にした翻訳専用設定を使います。通信やモデルが利用できない場合は、エラーを表示して原文を維持します。

対象は通常のHTML本文です。PDF・画像内の文字、別ドメインのiframe、Shadow DOM内の文章は対象外です。ボタンなどのイベントは維持しますが、ページ独自の処理が文章を書き直す場合があります。更新が多いページは一度の表示につき自動翻訳を10回までに制限し、必要なら「日本語訳」で追加分を翻訳します。サイトで不具合が起きる場合は自動翻訳をオフにして原文へ戻してください。

WebView2の標準翻訳は利用できないため、Atlas側で翻訳を実装しています。
